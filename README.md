# 台灣詐騙雷達（tw-scam-radar）

把可疑的簡訊、LINE 訊息或網址貼給 AI，它會告訴你像哪一種詐騙、紅旗在哪、對方接下來會要你做什麼、現在該怎麼做。

這是一份開源的**台灣詐騙手法庫**，加上一個讓 AI 照著判讀的 skill。用 skill 的話，判讀在你自己的電腦上、用你自己的 AI 跑，訊息不會送到我們這裡。

## 網頁版（不用安裝）

<https://tw-scam-radar.github.io/tw-scam-radar/>

貼上訊息就能檢查。先在你的瀏覽器裡做規則比對，判不出來可以再請 AI 看一次（每天名額有限）。請 AI 看的時候，訊息會經過我們的中繼程式送到 AI 服務，中繼程式不保存訊息內容。網頁不用登入、不用下載，也不會問你的個資或要你付錢。

## 安裝（Claude Code）

```
/plugin install tw-scam-radar --marketplace tw-scam-radar/tw-scam-radar
```

裝好之後，打 `/tw-scam-radar:check` 再貼上訊息；或直接貼訊息問「這是不是詐騙」，它也會自己啟動。需要電腦上有 Python 3，不用另外裝套件。

沒有設定 GitHub SSH 金鑰的話，安裝前先設定環境變數 `CLAUDE_CODE_PLUGIN_PREFER_HTTPS=1`。

更新：`/plugin marketplace update tw-scam-radar`。手法和 165 名單會持續更新。

## 用其他 AI 助理

下載這個專案，把 `skills/check/SKILL.md` 交給你的 AI，裡面寫了判讀步驟。不能跑 Python 的 AI 也能讀 `web/data/radar.json` 的手法庫自己判斷，只是少了規則比對和名單比對。

## 它怎麼判斷

1. **165 官方涉詐名單**：訊息裡的網址會比對內政部警政署公布的涉詐網站，目前 115,603 個網域。
2. **規則比對**：用 52 類手法的紅旗關鍵詞比對，例如「到 ATM 操作解除設定」「先繳保證金才能出金」「不要告訴家人」。也會認出轉傳的新聞和防詐提醒，避免把它們當成詐騙。
3. **AI 再判斷一次**：規則比對只抓得到三成左右，所以 skill 一定會讓 AI 讀手法庫，看對方假裝成誰、最後要你做什麼、有沒有逼你趕快、有沒有要你保密。

網頁版（`web/`）的做法一樣：規則比對在瀏覽器裡跑，判不出來時可以按「請 AI 判讀」。按下去的話，訊息會經過我們的中繼程式送到 AI 服務判讀，中繼程式不保存訊息內容。

## 這份手法庫是怎麼做出來的

完整數字與計算方式在 [`docs/STATS.md`](docs/STATS.md)。

- 52 類詐騙手法，分 9 大類。每一類都寫了開場、紅旗、對方最後要你做什麼、怎麼查證、被騙後怎麼辦，共 238 條紅旗，加上 21 條跨手法的共通紅旗。
- 272 筆參考來源，來自 71 個發布單位。其中 107 筆是官方或平台的一手說明（刑事警察局 35 筆最多，其次是金管會、各地檢署與警察局、數位發展部、衛福部、平台官方說明等），165 筆是主要媒體報導。每一類都附來源網址，50 類至少有兩個獨立來源互相印證。
- 165 官方名單：遭停止解析涉詐網站 93,839 筆、假投資（博弈）網站 45,258 筆，去重後 115,603 個網域。
- 真實回報訊息：[Cofacts 真的假的](https://cofacts.tw) 開放資料裡，被標成「詐騙」的回報訊息有 19,916 則（87% 由志工人工標記）。從中篩出 2023–2026 年的 7,240 則詐騙；另外從 Cofacts 篩出 1,887 則「有人懷疑過、查核後是真的」訊息當對照，一起拿來調整與測試。
- 民眾怎麼描述被騙：掃過 PTT、YouTube 留言、Dcard、Threads 等約 44 萬筆文字，找出 4,195 筆跟詐騙有關的內容，其中 596 筆能對應到特定手法。

## 準確度

規則是用一批資料調出來的，分數則用另一份**調整時完全沒看過的考卷**來量。AI 版是盲測：判讀的 AI 看不到答案、不能上網。

| 判讀方式 | 抓到詐騙 | 把正常訊息誤判成詐騙 |
|---|---|---|
| 規則比對（不用 AI，1,000 則考卷） | 31% | 10% |
| skill＋Claude Haiku 5.5（345 則考卷） | 88% | 7% |
| skill＋Claude Sonnet 5.5（同上） | 88% | 4% |
| skill＋Claude Opus 5.5（同上） | 90% | 2% |

skill 的分數是讓 AI 照 skill 的步驟判斷（先跑規則比對、再對照正常訊息長什麼樣子）量出來的；用 skill 的話，分數取決於你自己用哪個模型。

網頁版的 AI 從 2026-10-23 起改用 Claude Sonnet 5.5，網頁的寫法跟 skill 不同，這一版**還沒單獨量過**。改用之前的 Haiku 5.5 網頁版量到抓到 83%、誤判 16%，細節寫在 [`docs/STATS.md`](docs/STATS.md)。考卷裡的「正常訊息」是有人懷疑過、查核後沒問題的訊息，比日常訊息更像詐騙，平常使用的誤判應該會比表上低。

每個數字的誤差範圍（95% 信賴區間）與限制也都在 STATS 裡。考卷規模有限（規則比對 1,000 則、AI 判讀 345 則），數字會有誤差。手法庫只看得到公開報導或有人回報的騙法，新手法一定會晚一步。**沒有發現紅旗，不代表一定安全。有疑問請打 165。**

## 資料夾

| 路徑 | 內容 |
|---|---|
| `skills/check/` | 給 AI 的判讀步驟（skill） |
| `data/methods/` | 手法庫原始檔（YAML） |
| `data/official/` | 165 官方涉詐名單（精簡版）與來源標示 |
| `web/` | 網頁版（規則比對在瀏覽器裡跑，判不出來可以請 AI 再看一次） |
| `worker/` | 網頁版的 AI 中繼程式（每日上限、人機驗證、不保存訊息） |
| `tools/` | 檢查、比對、評分、更新名單的工具 |
| `tests/cases.yaml` | 測試案例 |
| `docs/` | 資料格式、數字出處、部署步驟 |

## 維護者用的指令

```bash
pip install pyyaml
python tools/validate.py            # 檢查格式、來源與個資
python tools/check.py "訊息內容"     # 判讀一則訊息
python tools/eval.py --show-misses  # 用測試案例評分
python tools/update_official.py     # 下載最新的 165 名單
python tools/build.py               # 打包給網頁版與 skill
```

## 回報判錯

判錯了（把正常訊息說成詐騙，或漏掉詐騙），請開 Issue，附上訊息內容，以及你覺得應該怎麼判。貼上之前先把姓名、電話、帳號遮掉。

# 網頁版設計（v1）

## 判斷流程

1. **規則比對（在使用者的瀏覽器裡跑，不花錢）**：手法庫紅旗＋165 官方涉詐網址名單。
2. 規則比對判成「高風險」或「可疑」→ 直接顯示結果，同時提供「我覺得不像，請 AI 再看一次」。
3. 判成「留意」「沒有發現已知紅旗」，或判斷這則是新聞／防詐提醒 → 顯示「規則判不出來」，提供「請 AI 判讀」按鈕。
4. AI 判讀走 `worker/`（Cloudflare Worker）：
   - 全站每日上限（`DAILY_LIMIT`）＋每個來源每日上限（`PER_CLIENT_LIMIT`），用完就請使用者打 165。
   - 防機器人灌額度：Cloudflare Turnstile（免費的人機驗證）。
   - 不保存訊息內容，只記當日次數。
   - 送出前提醒使用者先遮掉姓名、電話、帳號。

## 為什麼這樣分

兩份獨立考卷：規則比對大約抓到三成詐騙、AI 大約九成（見審閱報告）。規則先擋掉明顯的（官方名單、釣魚簡訊），判不出來的才花 AI 額度。

## 檔案

| 路徑 | 內容 |
|---|---|
| `web/index.html` | 介面（單頁、手機優先） |
| `web/radar.js` | 規則比對引擎（跟 `tools/check.py` 同一套邏輯，`tools/parity.py` 驗證兩邊結果一致） |
| `web/data/` | 由 `tools/build.py` 產生的 `radar.json`、`bad_domains.txt` |
| `worker/` | AI 中繼程式與每日上限 |
